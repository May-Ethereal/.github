# Support

Need help with a May Ethereal project? Use the right channel below.

| I want to… | Where to go |
| --- | --- |
| Report a bug | Open a **Bug report** issue in the relevant repository |
| Request a feature | Open a **Feature request** issue in the relevant repository |
| Ask a usage question | Open a **Question** issue, or start a Discussion if enabled |
| Report a vulnerability | Follow the [Security Policy](SECURITY.md) — **not** a public issue |
| Reach the org | <https://ethereal.tokyo/> |

## Before opening an issue

- Check the repository's `README` and documentation.
- Search existing open and closed issues.
- Provide enough detail to reproduce or understand your request.

Maintainers are volunteers; please be patient and respectful. Response times
are best-effort.
